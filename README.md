# owsLab

Bu proje ASP.NET Core kullanılarak geliştirilmiş bir web uygulamasıdır.

[![Demo'yu Görüntüle](https://img.shields.io/badge/Demo-GitHub%20Pages-blue?style=for-the-badge&logo=github)](https://erdemalpar.github.io/owsLab/)

## Proje Hakkında
owsLab, çeşitli web servisleri ve CBS (Coğrafi Bilgi Sistemleri) bileşenlerini test etmek/göstermek için oluşturulmuş bir çalışma ortamıdır.

## Kurulum ve Çalıştırma

Projeyi yerel bilgisayarınızda çalıştırmak için aşağıdaki adımları izleyebilirsiniz:

1. Depoyu klonlayın:
   ```bash
   git clone https://github.com/erdemalpar/owsLab.git
   ```
2. Proje dizinine gidin:
   ```bash
   cd owsLab
   ```
3. Uygulamayı çalıştırın:
   ```bash
   dotnet run
   ```
